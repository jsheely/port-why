---
title: Keyboard shortcuts
description: Keyboard controls for filtering and refreshing the port deck.
---

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Focus the filter | `Ctrl+F` | `Cmd+F` |
| Clear the filter | `Esc` | `Esc` |
| Rescan from scratch | `F5` | `Cmd+R` |

The list also refreshes automatically every two seconds.
